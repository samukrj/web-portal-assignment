# Campus Portal

A simple static web portal created as a university assignment.

## Pages
- Home
- About
- Resources
- Gallery
- Data
- Contact

## Features
- Custom CSS styling
- Gallery with image preview
- Contact form with client-side validation
- JSON data loaded into a table via JavaScript `fetch()`

## Technologies
- HTML
- CSS
- JavaScript

## How to Run

1. Clone or download the repository
2. Open the project in Visual Studio Code
3. Launch it using **Live Server** (or any local HTTP server)
4. Open `index.html` in your browser

> **Note:** Opening `index.html` directly in a browser (without a local server) is possible,
> but features like JSON loading may not work due to browser security restrictions.
